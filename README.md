## Диагностика подшипников ГТД по эксплуатационным данным

Проект на Streamlit для **раннего обнаружения повреждения подшипников опор газотурбинных двигателей (ГТД)**, эксплуатируемых в составе газоперекачивающих агрегатов (ГПА), по эксплуатационным CSV-данным.

Приложение загружает один или несколько файлов с временными рядами параметров, автоматически выделяет режимные и вибрационные признаки, обучает модель «нормы» по выбранной обучающей выборке и рассчитывает индекс технического состояния подшипников.

---

### Структура репозитория

- `streamlit_app.py` — основное веб-приложение Streamlit:
  - загрузка CSV-файлов;
  - выбор обучающей (эталонной) выборки;
  - обучение модели нормы (кластеризация режимов, Махаланобисово расстояние по вибропризнакам);
  - расчёт индекса состояния `H` и сглаженного индекса `H_smooth`;
  - визуализация временных графиков и таблица аномальных точек.
- `requirements.txt` — список Python-зависимостей.
- `.gitignore` — игнорируемые файлы/папки для Git.

---

### Ожидаемый формат входных данных

- Формат файлов: `CSV` с разделителем `;` и десятичным разделителем `,`.
- Обязательный столбец: `Дата и время` (будет преобразован в `datetime`, формат `ДД.ММ.ГГГГ ЧЧ:ММ:СС`).
- Ожидаются столбцы **режимных параметров** (часть из них может отсутствовать, используется только то, что найдено):
  - `N1`, `N2`, `N3`, `Qtg`, `Pm`, `P2`, `ТРК`.
- Ожидаются столбцы **вибрационных/диагностических параметров**:
  - `Lm1`, `F1`, `F2`, `2F1`, `2F2`, `3F1`, `3F2`, `Fc2`, `Fc3`, `Fc4`, `Fкпа`, `Fцс`.

Как минимум должно найдтись несколько режимных и несколько вибрационных признаков — приложение покажет, какие именно были использованы.

Рекомендуется иметь отдельный файл с **обучающей (эталонной) выборкой**, соответствующей заведомо исправному состоянию подшипников (например, `Обучающая выборка.csv`).

### Локальный запуск

1. Клонировать репозиторий:

   ```bash
   git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>.git
   cd <имя_репозитория>
   ```

2. Установить зависимости (Python 3.9+):

   ```bash
   pip install -r requirements.txt
   ```

3. Запустить Streamlit-приложение:

   ```bash
   streamlit run streamlit_app.py
   ```

4. В открывшемся в браузере интерфейсе:
   - загрузить файлы `КС-1.csv`, `КС-2.csv`, `Обучающая выборка.csv` (или аналогичные);
   - выбрать в выпадающем списке файл, соответствующий обучающей выборке;
   - при необходимости настроить:
     - число кластеров режимов,
     - окно сглаживания индекса,
     - значения предупредительного и аварийного порогов.

Приложение обучит модель «нормы» по выбранной обучающей выборке и рассчитает индекс состояния для всех загруженных данных.

### Развёртывание на Streamlit Cloud

1. Загрузите этот репозиторий на GitHub.
2. В Streamlit Cloud создайте новый проект, указав URL репозитория.
3. В настройках проекта:
   - в качестве **main file** укажите `streamlit_app.py`;
   - убедитесь, что используется `requirements.txt` из репозитория.
4. После первого развёртывания приложение будет доступно по сгенерированной ссылке.

В Streamlit Cloud пользователь также загружает свои CSV-файлы и запускает все расчёты и обучение модели непосредственно в браузере.

### Кратко об алгоритме

- По режимным признакам (`N1`, `N2`, `N3`, `Qtg`, `Pm`, `P2`, `ТРК`) данные разбиваются на несколько **кластеров режимов работы** (KMeans).
- Для каждого кластера по вибропризнакам (`Lm1`, `F1`, `F2`, `2F1`, `2F2`, `3F1`, `3F2`, `Fc2`, `Fc3`, `Fc4`, `Fкпа`, `Fцс`) строится модель нормы (многомерное нормальное распределение, эмпирическая ковариационная матрица).
- Для каждой новой точки рассчитывается **Махаланобисово расстояние** до центра «нормы», которое нормируется в индекс `H ∈ [0, 1]`.
- Индекс сглаживается по времени (`H_smooth`), и по его росту и превышению порогов формируются **предупредительные** и **аварийные** сигналы о возможном развитии повреждения подшипников.
